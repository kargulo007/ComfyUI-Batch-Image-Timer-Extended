# Contributing

Contributions are welcome to this independent community edition. Before reporting an issue, verify it occurs with the current Extended release and not when the original and Extended nodes are installed simultaneously.

## Bug reports
Provide steps to reproduce, expected/actual behavior, ComfyUI version, operating system, selected GPU, logs (redacted), and a minimal workflow if it can be shared safely.

## Pull requests
- Keep changes scoped and backward compatible when possible.
- Never commit `data/`, exported settings, local databases or personal workflows.
- Preserve the original upstream license and attribution.
- Include or update a changelog entry for user-facing modifications.
- Ensure Python source compiles and frontend JavaScript passes syntax checks.
- Describe any SQLite schema changes and a safe migration path.

## Versioning
This repository uses its own **Extended** version numbering. Do not confuse these tags with releases from Herman Kwan's upstream repository.
